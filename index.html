02Memory engine

Writes nothing it isn’t sure about.

Vanta brings its own engine. Every cheat finds its code with a byte pattern that has to match exactly once. No match, or more than one, and nothing is written. Turn a cheat off, detach or close the app, and every byte goes back the way it was.

  1. scan48 8B 05 ?? ?? ?? ?? 89 88 F0 00 00 00
  2. match1 of 1 unique, safe to patch
  3. patchwritten original bytes kept
  4. offrestored byte for byte

    07Get started

      Extract the zip to its own folder, for example C:\Games\Vanta. .NET is built in.

    2. 2

      Open Vanta.exe, pick a game and hit Start. Vanta launches it through your launcher and attaches.

    08FAQ

    Questions, answered.

    Something else? Open an issue on GitHub.

    Is Vanta really free?

    Yes. Vanta is free and open source under the MIT license. No ads, no accounts, no paid tiers.

    Do I need Cheat Engine?

    No. Vanta has its own memory engine and runs on its own. Download, unzip and start Vanta.exe.

    Can I get banned?

    Vanta only supports offline singleplayer games and refuses games with online anti-cheat. Don’t use it online or in co-op. That is both the rule and the safest way to play.

    Windows says the file might be unsafe. Why?

    The exe isn’t code-signed, which makes SmartScreen cautious about any new download. Click More info, then Run anyway. You can compare the zip with the published SHA-256 checksum, and the full source is on GitHub.

    My game updated and a cheat stopped working.

    Vanta checks the game version and tells you when it doesn’t recognise a build. Updated cheats arrive automatically with new releases. Reporting it from the app gets it picked up faster.

    Which games are supported?

    The current list is always inside the app. New games are added regularly, and you can request and vote for the next ones from Vanta itself.

    What do I need to run it?

    Windows 10 or 11 (64-bit) with the Microsoft Edge WebView2 Runtime, which comes with Windows 11 and most Windows 10 installs.

    Does Vanta collect data?

    Not unless you choose to. Signing in with Discord for community reports and sharing anonymous usage counts are both optional and off by default. Read the privacy notes.
