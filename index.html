What is Vanta

A trainer that feels like a launcher, not a hacking tool. Vanta finds your games, attaches when they start and gives you a clean list of cheats written for your exact game version.

Everything you need. Nothing you don't.

Its own memory engine

No Cheat Engine underneath. Every cheat looks for its code with a byte pattern that must match exactly once, otherwise Vanta writes nothing. Turn a cheat off, detach or close Vanta and every byte goes back exactly as it was.

Cheats per game

Each game gets its own hand-tuned set: toggles, sliders, multipliers and one-shot buttons, grouped and named in plain language.

Hotkeys CtrlF1

Toggle cheats without leaving the game. Every hotkey can be rebound, cleared or reset per game.

Automatic updates

New versions arrive from GitHub while you use the app, verified with SHA-256, with a backup and automatic rollback if something goes wrong.

Version checks

Vanta fingerprints your game build before touching it. A game patch it doesn't know yet? You'll see it right away instead of a crash.

Community reports

Optionally sign in with Discord to report whether a cheat works in your version, and see what other players found. Never required.

Finds your games, wherever you bought them

Vanta detects installs from every major launcher and starts the game through the right one, so DRM and overlays keep working.

    Get started

    Up and running in a minute.

    1. 01

      Download & unzip

      Extract the zip to its own folder, for example C:\Games\Vanta. Nothing to install; .NET is built in.

    2. 02

      Start your game

      Open Vanta.exe, pick a game and hit Start. Vanta launches it through your launcher and attaches automatically.

    3. 03

      Flip the switches

      Turn cheats on in the app or with hotkeys. Close Vanta and your game is back to normal.

    Single-player only

    Built for playing alone. On purpose.

    Cheats can still cause crashes or odd saves. Keep a backup of saves you care about.

    Safety rules4/4
    • Games with online anti-cheat are refused. If Vanta finds anti-cheat files, it won't attach. Period.
    • No multiplayer, no co-op. Use cheats in your own offline or solo campaign, never against or alongside other people.
    • Nothing permanent. Vanta patches game memory while it runs and restores it when you stop. Your game files are never modified.
    • Open source. Every line is on GitHub. The exe isn't code-signed, so Windows SmartScreen may ask you to confirm the first start.

    FAQ

    Questions, answered.

    Is Vanta free?

    Yes. Vanta is free and open source under the MIT license. There are no ads, no accounts and no paid tiers.

    Do I need Cheat Engine?

    No. Vanta has its own memory engine and runs on its own. Just download, unzip and start Vanta.exe.

    Can I get banned?

    Vanta only supports single-player games and refuses games with online anti-cheat. Don't use it online or in co-op. That's both the rule and the safest way to play.

    Windows says the file might be unsafe. Why?

    The exe isn't code-signed, which makes SmartScreen cautious about any new download. Click More info and then Run anyway. You can compare the zip with the published SHA-256 checksum, and the full source is on GitHub.

    My game updated and a cheat stopped working.

    Vanta checks the game version and tells you when it doesn't recognise a build. Updated cheats arrive automatically with new Vanta releases. You can also report it from the app so it gets picked up faster.

    Which games are supported?

    The current list is always inside the app. New games are added regularly, and you can request and vote for the next ones from Vanta itself.

    What do I need to run it?

    Windows 10 or 11 (64-bit) with the Microsoft Edge WebView2 Runtime, which comes with Windows 11 and most Windows 10 installs.

    Does Vanta collect data?

    Not unless you choose to. Signing in with Discord for community reports and sharing anonymous usage counts are both optional and off by default. See the privacy notes.
